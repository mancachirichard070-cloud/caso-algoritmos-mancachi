# H1: Registro de ventas y control de inventario de detergentes

El proceso que se analizará es el registro de ventas y el control de inventario de detergentes de un pequeño negocio.
La actividad comienza cuando se concreta una venta y se identifica la presentación del producto solicitado.
Actualmente, se comercializa detergente de la marca UNO en dos presentaciones: 620 g y 4,7 kg.
El precio de venta es de Bs 12 por unidad para la presentación de 620 g y Bs 90 para la de 4,7 kg.
En cada operación se debe registrar la fecha, el producto vendido, la cantidad y el precio unitario.
Con esos datos se calcula el importe total de la venta y se actualiza la cantidad disponible en el inventario.
En algunas ocasiones se venden varias unidades en una sola operación, incluso 15 unidades.
El registro y la revisión de las existencias pueden tomar alrededor de 30 minutos al día.
Este tiempo se utiliza principalmente en anotar las ventas, realizar cálculos y verificar las unidades disponibles.
Si la información no se actualiza oportunamente, pueden producirse diferencias entre el inventario registrado y las existencias físicas.
Esto también puede ocasionar que se ofrezca al cliente un producto que ya no se encuentra disponible.
Por ello, se busca organizar el registro de las operaciones, agilizar el cálculo de los importes y mantener actualizado el inventario.
Para el análisis se utilizará un archivo CSV con los datos de las ventas realizadas, organizado por fecha, producto, cantidad, precio unitario y total.
