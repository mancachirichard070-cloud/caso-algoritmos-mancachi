# Richard Mancachi Tantani
## Repositorio - Analisis de Algoritmos

Este repositorio contiene el desarrollo de mis actividades, practicas, hitos y evaluaciones de la materia Analisis de Algoritmos.

## 1. H1 - Registro de ventas e inventario

Caso: Registro de ventas y control de inventario de detergentes UNO.

Se trabaja con dos presentaciones:
- UNO de 620 g: Bs 12.
- UNO de 4,7 kg: Bs 90.

Se analizan los registros de ventas, las operaciones del inventario y las estructuras de datos que permiten mejorar su administracion.

**Carpeta:** [H1](H1/)

## 2. Practicas de laboratorio

Contiene las actividades practicas desarrolladas durante la materia, incluyendo ejercicios de algoritmos y estructuras de datos.

**Carpeta:** [Practicas](practicas/)

## 3. H2 - Estructuras de datos

Se analiza la seleccion de estructuras de datos para el caso de ventas e inventario.

Incluye:
- Inventario de operaciones.
- Eleccion y justificacion de estructuras.
- Comparacion entre una solucion ingenua y una mejorada.
- Mediciones de rendimiento.

**Carpeta:** [H2](hitos/h2/)

## 4. H3 - Algoritmos voraces y programacion dinamica

Se desarrolla un problema analogo basado en los productos UNO, utilizando el problema de la mochila 0/1.

Se implementan y comparan:
- Algoritmo voraz (Greedy).
- Fuerza bruta.
- Programacion dinamica.

Se comprueba la diferencia entre una decision local y una solucion optima mediante pruebas y mediciones.

**Carpeta:** [H3](hitos/h3/)

## 5. Parcial 2 - Variante A

Implementacion de un sistema de turnos de una clinica, comparando una solucion ingenua con una estructura mejorada.

**Carpeta:** [Parcial 2](parcial2/)

## 6. Proceso de aprendizaje

El desarrollo del repositorio sigue una secuencia de trabajo:

1. Identificacion y analisis de problemas.
2. Seleccion de estructuras de datos.
3. Implementacion de algoritmos en C#.
4. Pruebas funcionales.
5. Mediciones de rendimiento.
6. Analisis de complejidad y conclusiones.
